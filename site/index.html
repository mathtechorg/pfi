About the guide

PreTeXt can now be used to create accessible, web-based course materials that are easy to maintain and update. Some of what you will learn:

  • Run PreTeXt in a browser or install locally.
  • Create an entire course "book" complete with a syllabus, printable activities, and notes.
  • Create lecture slides.
  • Convert existing materials to PreTeXt.
  • Host your entire course for free using GitHub Pages.
  • Embed pages for your course inside your LMS.

For more information about PreTeXt, visit the PreTeXt website.
