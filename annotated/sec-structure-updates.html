  <title>First Edits</title>

  <p>
    Let's make our course our own by updating some of the basic course information.
  </p>

  <paragraphs>
    <title>Change the course title</title>
    <p>
      Open the <c>main.ptx</c> file (inside the <c>source</c> folder).  The top of the file will have the following lines.
    </p>

    <program language="xml" line-numbers="yes">
      <code>&lt;?xml version="1.0" encoding="UTF-8"?&gt;

&lt;!-- This is the main course file for ... . It is used to generate all the public facing course materials so those can be hosted online.  --&gt;
&lt;pretext xmlns:xi="http://www.w3.org/2001/XInclude"&gt;
  &lt;!-- Include common macros etc: --&gt;
  &lt;xi:include href="./docinfo.ptx" /&gt;
  &lt;!-- By creating a PreTeXt "book" for the course, we can split components into "chapters" --&gt;
  &lt;book&gt;
    &lt;title&gt;Course Name (change me)&lt;/title&gt;
</code>
    </program>

    <p>
      Let's take it line-by-line.  The first line is the XML declaration, which should be included in all PreTeXt files (and will be automatically added if missing when you format your code).  This just identifies the file as XML.
    </p>

    <p>
      Lines 3, 5, and 7 are comments.  In XML a comment starts with <c>&lt;!--</c> and ends with <c>--&gt;</c>.  Comments are ignored by PreTeXt and are just there to help human readers understand the source.  You can change or delete these comments as you like.
    </p>

    <p>
      Line 4 is the opening <tag>pretext</tag> element.  This identifies this file as a PreTeXt document (all the way at the bottom of the file is the closing <tag>/pretext</tag> element, indicating the end of the document).  The <attr>xmlns:xi</attr> attribute declares the XML namespace for XInclude, which is needed to use the <tag>xi:include</tag> element later in the file.
    </p>

    <p>
      That is what happens on line 6, where we include the <c>docinfo.ptx</c> file that contains common macros and other information for the course.
    </p>

    <p>
      Finally on line 8 we open the <tag>book</tag> element, which contains all the content for the course.  And directly after this on line 9 (the first child of the <tag>book</tag>) is the <tag>title</tag> element, which contains the title of the course.  Let's change that now.
    </p>

    <p>
      It is the contents of this <tag>title</tag> element that will appear as the main title of the course in the generated output.  Change the text <c>Course Name (change me)</c> to the actual name of your course.  We will call our course <em>PreTeXt by Example</em>, so our updated line 9 looks :
      <cd>
        <cline>&lt;title&gt;Demo PreTeXt Course&lt;/title&gt;</cline>
      </cd>
    </p>

    <p>
      Let's also update the subtitle (on line 11) to look something like this:
      <cd>
        <cline>&lt;subtitle&gt;PTX 101 Spring 2026&lt;/subtitle&gt;</cline>
      </cd>
    </p>

    <p>
      Now we can rebuild the course (see <xref ref="sec-workflow-build"/>) and see our updated title and subtitle in the output (go back to the tab where the course is open and refresh the page to see the changes, or run <c>pretext view</c> if you have closed that tab).
    </p>
  </paragraphs>

  <paragraphs>
    <title>Changing Author Information</title>

    <p>
      The next non-comment line in the <c>main.ptx</c> file is the inclusion of the <c>frontmatter.ptx</c> file.  You can open this file by finding it in the explorer panel on the left side of the screen, or by clicking on the link in the <attr>href</attr> attribute of the <tag>xi:include</tag> element, while holding down the <c>Ctrl</c> key (or <c>Cmd</c> on a Mac).
    </p>

    <p>
      In the <c>frontmatter.ptx</c> file, we see the root element is <tag>frontmatter</tag>; since we included this file using the <tag>xi:include</tag> mechanism, we can only have one root element.  The entire contents of this element (including the start and end tags) will be inserted into the parent document (<c>main.ptx</c> in this case) at the location of the <tag>xi:include</tag>.
    </p>

   <program language="xml">
    <code>&lt;frontmatter xmlns:xi="http://www.w3.org/2001/XInclude" xml:id="frontmatter"&gt;
  &lt;bibinfo&gt;
    &lt;author&gt;
      &lt;personname&gt;Instructor Lastname&lt;/personname&gt;
      &lt;department&gt;Mathematical Sciences&lt;/department&gt;
      &lt;institution&gt;University of Templates&lt;/institution&gt;
    &lt;/author&gt;
    &lt;date&gt;
      Last Updated: &lt;today /&gt;
    &lt;/date&gt;
  &lt;/bibinfo&gt;

  &lt;!-- This displays the title page information --&gt;
  &lt;titlepage&gt;
    &lt;titlepage-items/&gt;
  &lt;/titlepage&gt;

&lt;/frontmatter&gt;</code>
   </program>

    <p>
      The two child elements of <tag>frontmatter</tag> are <tag>bibinfo</tag> and <tag>titlepage</tag>.  The first of these contains information about authors and other document data.  Go ahead and change the author information here.  You can also read the <url href="https://pretextbook.org/doc/guide/html/topic-front-matter.html#topic-front-matter-3">Bibinfo section of the PreTeXt Guide</url> for additional content you can add to this element.
    </p>

    <p>
      The <tag>titlepage</tag> element contains a <term>generator</term> element, <tag>titlepage-items</tag> which will automatically insert the parts of bibinfo that should go on a title page.  So don't edit anything there.
    </p>

    <p>
      Go ahead and rebuild the course and see the changes.  At this point you might also want to see what happens if you remove the frontmatter element entirely (should a <q>course</q> have frontmatter?).  You can return to the <c>main.ptx</c> file and comment out the <tag>xi:include</tag> element that includes the frontmatter.
    </p>

    <insight>
      <title>Keyboard Shortcut for Comments</title>
      <p>
        In VS Code, you can toggle comments for one or more lines with the <kbd>CTRL</kbd>+<kbd>/</kbd> shortcut (or <kbd>⌘</kbd>+<kbd>/</kbd> for Mac).
      </p>
      
    </insight>
  </paragraphs>

  <paragraphs>
    <title>Next Steps</title>
    <p>
      Now would be a good time to save our work.  Commit and sync your repository as described in <xref ref="sec-workflow-save"/>.
    </p>

    <p>
      Next up we will start adding components of the course, starting with a syllabus.
    </p>

        </p>
      </introduction>
